# Basic Linux Commands

## Overview
This project demonstrates basic Linux command-line operations completed as part of cybersecurity training.

## Commands Practiced
- `pwd` — Displays the current working directory.
- `whoami` — Displays the currently logged-in username.
- `ls` — Lists files and directories.

## Platform
TryHackMe

## Objective
To understand and practice fundamental Linux commands used in cybersecurity and system administration.

Screenshots of the command outputs are included in the project documentation.
